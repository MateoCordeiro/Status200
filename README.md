## Branch Naming Convention

Every piece of work gets its own branch, named:

```
FeatureName-INITIALS
```

For example: `TurnOffLight-MPC`

- **Feature name:** `PascalCase`, describing what the branch does (`TurnOffLight`, `FixLoginCrash`).
- **Initials:** the author's initials in uppercase, as listed in the Contributors table.
- **Separator:** a single hyphen between the two.
- **One feature per branch.** Changes go into `main` through a pull request, not by committing to it directly.
